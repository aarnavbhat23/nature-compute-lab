# Useful partnerships between modules

Two elementary modules learn their own readouts from noisy component measurements. A composition program can connect existing outputs through multiplication. Greedy training-error proposals create joins; validation selects when to stop. A join can itself participate in a later join, so the result is an executable hierarchy.

Both controls use the same fitted intermediate modules and have access to the same component measurements. The independent control combines them additively; the strong control fits all polynomial interactions through degree four. Training excludes the joint extreme-input region used for testing. All candidate programs are selected before test evaluation.

This is a small program-induction abstraction of symbiosis. It does not establish autonomous emergence, endosymbiosis, or new primitive discovery. The generator is favorable to multiplication, and the small join grammar is supplied by hand. A future experiment should remove component labels and use compositions outside that grammar.

Initial five-seed run: the program retained two joins in every seed. Mean held-out MSE was 1.92e-4, versus 6.76e-2 for independent modules and 6.76e-4 for the full fixed interaction dictionary. This is evidence for a compact composition on this matched task; it is not evidence of superiority outside the supplied operation family. The full-dictionary regularization has not received an extensive tuning sweep.
